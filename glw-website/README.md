# 光联微 GLW 品牌官网 · 静态设计初稿

电子元器件分销公司官网。纯 HTML / CSS / JavaScript，无构建依赖、无后端接口、无 CDN 字体或远程图片，所有插画均为原创本地 SVG。与 glw-web ERP 前端、glw-backend 后端独立。

## 预览

直接打开 `index.html` 即可离线浏览。也可以启动本地静态服务：

```powershell
cd E:\PycharmProject\glw-erp\glw-website
python -m http.server 5174 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:5174 。后续可以直接部署到 Nginx 或任意静态站点托管。

## 设计方向

- 深海蓝、青绿色与暖白的半导体科技视觉。
- 独立的光联微概念标识与原创等距芯片、电路、行业场景插画。
- 内容顺序：品牌首屏 → 产品检索 → 六类产品 → 应用领域 → 供应链服务 → 公司简介 → 选型笔记 → 商务联系。
- 电脑、平板、手机响应式布局，支持键盘操作、弹窗焦点管理和减少动画偏好。

## 可操作功能

- 页内导航与滚动高亮，移动端折叠菜单、返回顶部。
- 产品关键词搜索、分类筛选、清空筛选、空结果反馈、产品详情弹窗。
- 四个应用场景切换；应用页签支持左右方向键及 Home/End。
- 三篇原创通用选型笔记详情。
- 询价表单必填与联系方式校验，根据产品/场景自动带入需求方向。
- 生成本地询价草稿、继续编辑、下载 UTF-8 文本清单。
- 隐私说明；表单不会上传、发送或保存到 localStorage。

## 正式上线前需要提供的内容

当前仅确认公司全称为“光联微电子有限公司”，品牌简称为“光联微”、主营业务为电子元器件分销。其余品牌定位与栏目文案为设计建议，需要公司确认。

- 公司全称、正式 Logo、介绍、地址、电话、商务邮箱。
- 实际经营产品线、型号、品牌关系、可展示的授权或资质。
- 实际服务内容、案例及可公开图片。
- 备案信息（如适用）、正式隐私说明、询价接收方式。

页面没有虚构成立年份、代理授权、库存、交期承诺、客户数量、联系方式或新闻事件。产品均为类别展示，不是可售现货目录；场景插画不代表公司厂房或客户案例。页脚标明设计预览状态。询价按钮只生成本地草稿，正式接入邮件或后端后需调整交互与隐私说明。
