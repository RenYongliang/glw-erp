# 采购管理页面

入口：`/purchase/orders`（采购订单）、`/purchase/receipts`（采购入库），均沿用项目登录保护。

参照简道云进销存模板中的采购订单及采购入库页面，保留分组表格、视图页签、绿色操作按钮、蓝色表单分区、选择数据弹窗及产品子表。初始提供 26 条订单、23 条入库记录，产品使用电子元器件演示数据。

## 演示流程

1. 采购订单点击“添加”，选择供应商、签订/交付日期、仓库和产品。数量、含税单价、税率、优惠金额联动计算金额和人民币大写；到货计划、付款计划可增删。
2. 提交后进入“待审批订单”。打开详情，可审批通过或填写不通过原因；无关联记录的订单可修改并重新提交审批。
3. 已审批订单的“采购入库”自动带入订单、供应商、仓库和剩余数量。到货数量减去不合格数量得到入库数量，可分批入库。
4. 未勾选确认时存入“待入库”，已占用本次合格品数量，防止重复创建超额入库单。勾选“合格品入库确认”后须填写仓位、入库员和时间。已保存的单据不能更换订单。
5. 订单行的采购付款和采购退货打开本地录入弹窗。付款不能超过剩余订单金额，退货不能超过已确认入库且未退货的数量。详情页关联页签展示这些记录。

列表支持页签、关键字搜索、字段筛选、升降序、字段显示、分组展开/收起、多选删除、行高、表格全屏和刷新。有关联记录的订单不允许删除或改动基础信息；有退货记录的订单不允许修改或删除入库单。

## 本地数据与导入导出

- 数据存储于当前浏览器的 `localStorage['glw.purchase.v1']`，刷新保留；不同浏览器独立。没有采购后端接口，也不会修改服务器数据库。
- 导入使用 UTF-8 CSV，先下载弹窗中的模板。订单按同名订单合并多条产品，入库按订单编号合并；整批校验成功才保存，最多 500 行。导入订单为待审批，入库为待入库。
- 导出为当前显示字段的 CSV，有选中行时只导出所选。列表导出用于查看，批量导入使用专用导入模板。
- 附件和入库照片作为本地预览保存，每个不超过 2MB；不是远程上传。存储不足时明确报错，不显示保存成功。
- 所有审批、付款和退货为前端模拟，不产生实际资金往来。现有经营看板仍使用自己的演示数据，采购模块尚未接入统一库存、财务后端。
