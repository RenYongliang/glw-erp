# 销售管理页面

- 销售订单：`/sales/orders`
- 销售出库：`/sales/shipments`

页面已接入 Vue 3 路由和销售管理菜单，沿用现有项目外壳及采购页面的基础样式。模板参考资料保存在 `first-django/sales-management-stage` 下的页面截图、HTML 和表单文本中。

## 可操作范围

销售订单支持客户/产品选择、价格等级、数量与金额计算、送货和收款计划、合同附件、审批，以及关联出库、收款和退货信息。

销售出库支持选择已审批且仍有可出库数量的订单，自动带入客户及产品，增删本次出库产品、部分出库、仓位、库存冻结/计划出库标签、出库确认、图片和客户收货确认。已确认出库的单据锁定出库信息。

两个列表支持视图切换、搜索、字段筛选、排序、列显示、客户分组、展开/收起、勾选、导入导出 CSV、删除校验、操作记录、行高和全屏。出库导入模板使用当前符合条件订单的仓库和产品编码。

## 数据边界

这是可交互的前端原型，销售单据保存于当前浏览器的 `localStorage`（`glw.sales.v1`），尚未接入 Spring Boot 销售接口。库存、审批、收款、退货为本地模拟，不会改动后端库存或财务数据。报价单字段可选择/录入编号，尚未连接报价业务。附件为本地存储，每文件上限 2MB。

默认登录配置保持后端模式。独立预览可在 PowerShell 中临时设置 `$env:VITE_AUTH_MODE='mock'`，再执行 `npm.cmd run dev -- --host 127.0.0.1 --port 5174`；演示账号 `admin`，密码 `Admin123!`。

## 验证

- `npm.cmd run build`：TypeScript 检查及生产构建。
- `node --test tests/*.test.mjs`：包含销售金额、库存占用、出库校验、收货时间和退货计算。
- `first-django/sales-management-stage/check.cjs`：新增订单 → 审批 → 部分出库 → 收货确认 → 刷新持久化及移动端。
- `first-django/sales-management-stage/controls.cjs`：列表工具栏、CSV、产品增删、标签切换、退出保护。

浏览器脚本使用独立临时浏览器上下文，不写入用户日常浏览器数据。默认测试地址为 `http://127.0.0.1:5174`。
