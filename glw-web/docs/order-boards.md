# 销售和采购订单看板

入口：经营看板菜单、首页同名快捷入口。

- `/boards/sales`：销售订单统计 / 销售订单-出库-退换货-对账执行统计。
- `/boards/purchase`：采购订单统计 / 采购订单-入库-退货-对账执行跟踪。

## 数据与口径

`src/data/orderBoards.json` 是从用户指定的简道云公开模板页面读取的示例数据快照，仅在本地显示，不访问生产业务接口。
销售包含 19 笔订单、76 条产品明细；采购包含 24 笔订单、47 条产品明细。
销售指标合计订单金额 6,510,150.00 元；采购指标按产品明细金额合计 3,435,860.00 元。
原模板的订单金额、产品明细合计和执行对账金额存在差异，保留各自原值，不强行改写为同一口径。
数据日期覆盖 2023、2024、2026 年，选择“今天”等动态日期可能没有记录，属于正常空状态。

## 交互

文本字段支持等于、不等于、等于任意一个、不等于任意一个、包含、不包含、为空、不为空；下拉支持搜索、全选、清空及未填写。
日期支持单日、范围、比较运算符、动态日期预设及自定义范围；动态日期以浏览器本地日期为基准。
统计筛选联动指标、趋势和订单表；执行跟踪页使用独立筛选，支持四种业务状态标签及客户/供应商和订单名称筛选。
统计表按订单分页（20/50/100），执行表按产品明细每页 50 行分页，跨页重新计算合并单元格。
统计表支持表头排序、排序设置、列宽拖动、左右滚动、固定列、行点击只读明细及上一笔/下一笔。
工具栏支持刷新、重置、表格全屏和本地 CSV 导出；采购执行表汇总当前全部筛选结果。
本地 CSV 导出为补充功能；无模板安装、账号权限、审批提交或远程数据写入。
